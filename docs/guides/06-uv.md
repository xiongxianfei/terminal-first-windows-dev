# uv Setup

## Purpose

Install `uv` as an optional Python package and project tool for Windows PowerShell and Ubuntu.

## Command environment

- Windows PowerShell: Windows `uv` install, update, and verification.
- Ubuntu shell: Linux `uv` install, update, source configuration, and verification.

## Safety notes

- `uv` is optional in this first slice.
- Do not commit private package indexes, credentials, tokens, or internal hostnames.
- Prefer project-level index configuration for project-specific mirrors.
- Prefer user-level configuration only for personal workstation defaults.

## Install uv on Windows

Run in Windows PowerShell:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Restart PowerShell or refresh the environment, then verify:

```powershell
uv --version
```

## Install uv on Ubuntu

Run in Ubuntu:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Restart the shell or source the shell profile modified by the installer, then verify:

```bash
uv --version
```

## Update uv

When installed by the standalone installer, update with:

```bash
uv self update
```

Run the same command from Windows PowerShell or Ubuntu, depending on which environment owns the installed `uv` binary.

If `uv` was installed through another package manager, update it through that same package manager instead.

## Configure package indexes

By default, `uv` uses PyPI. For a project-specific mirror or private index, prefer `pyproject.toml`:

```toml
[[tool.uv.index]]
name = "internal"
url = "https://packages.example/simple"
default = true
```

For a user-level workstation default, use `uv.toml` in the user config directory:

```toml
[[index]]
name = "internal"
url = "https://packages.example/simple"
default = true
```

Use environment variables only for temporary shell sessions or secret-free examples:

```bash
export UV_DEFAULT_INDEX="https://packages.example/simple"
```

Best practices:

- Use `[[tool.uv.index]]` in `pyproject.toml` when the source is part of the project contract.
- Use user-level `uv.toml` when the source is a personal or corporate workstation default.
- Keep credentials out of config files. Use environment variables, keyring, or policy-approved credential storage.
- Keep the default `first-index` strategy unless you intentionally accept dependency-confusion risk.

## Verification

Run:

```bash
uv --version
uv python list
```

For index configuration, test with a package approved for the selected source:

```bash
uv pip install --dry-run --default-index https://packages.example/simple <package-name>
```

## Validation

- Windows and Ubuntu install paths are documented.
- `uv self update` is documented for standalone installer installs.
- Package-index configuration documents project-level `pyproject.toml`, user-level `uv.toml`, and temporary `UV_DEFAULT_INDEX`.
- Private indexes, credentials, tokens, and internal hostnames are not committed.

## Rollback

Remove the installed `uv` binary through the same install channel used to install it. Remove only the user-level or project-level `uv` config entries you created.
